Punteros :O

Variable donde se guarda una dirección en memoria de dato (otra variable).

*:Declarar punteros, obtener/modificar valor de puntero
&: dirección de memoria de variable de dato

Se declara con un tipo de dato

int var=3;
int *ptr;
ptr=&var;
printf("el num es: %i",*ptr);

*p=*p+1 suma 1 al valor guardado
----------------------------------------------------------------------------
void swap(int *p1, int *p2){
    int aux=*p1;
    *p1=*p2;
    *p2=aux;
}

int main(){
    int n1,n2;
    int *p1,*p2;
    p1=&n1;
    p2=&n2;
    scanf("%i",&n1);
    scanf("%i",&n2);
    swap(p1,p2);
    printf("n1: %i, n2: %i\n",*p1,*p2);
    printf("p1: %i, p2: %i",p1,p2);
    return 0;
}
------------------------------------------------------------------------------

Punteros se mueven por posiciones de memoria, y se puede operar sobre las mismas para moverlos.
El tipo de dato de un puntero le indica la cantidad de espacio en memoria que ocupa el dato, y las operaciones usan esa dimensión:
*ptr=&var
ptr+=1

pasa a la 'siguiente' dirección en memoria (el byte después del dato al que refiere)
Si ptr es char: siguiente byte
si ptr es int: 4 bytes después
etc

*p=*(p+1) obtiene val del siguiente y guarda

vectores contienen la dir del primer elemento, por lo que:
int vec[n], *ptr;
ptr=vec // =ptr=&vec[0]

--------------------------------------------------------------------------------
void mostrar(int *ptr){
    for (int i=0;i<10;i++){
        printf("%i\n", *(ptr+i));
    }
}

void cargar(int *ptr){
    int n;
    for (int i=0;i<10;i++){
        printf("Ingrese numero: ");
        scanf("%i",&n);
        *ptr=n;
        ptr+=1;
    }
}

int main(){
    int vector[10];
    int *ptr;
    ptr=vector;
    cargar(ptr);
    mostrar(ptr);
    return 0;
}


a cada función le pasa el puntero por copia, y sabiendo el tamaño del vector se pueden usar ciclos de operación para trabajar conociendo únicamente la posición base del puntero
